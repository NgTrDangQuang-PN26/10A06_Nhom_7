# THPT Phú Nhuận — Website giới thiệu

Website landing page giới thiệu Trường THPT Phú Nhuận, thiết kế theo phong cách hiện đại, responsive và có thể chạy trực tiếp trên GitHub Pages.

## Cấu trúc

- `index.html` — nội dung trang
- `style.css` — giao diện responsive
- `script.js` — menu mobile + hiệu ứng xuất hiện khi cuộn

## GitHub Pages

Vào **Settings → Pages** của repository và chọn:

- **Source:** Deploy from a branch
- **Branch:** `main`
- **Folder:** `/(root)`

Sau đó GitHub sẽ cấp URL Pages cho repository.

## Nguồn nội dung

Nội dung được đối chiếu với cổng thông tin chính thức của THPT Phú Nhuận, đặc biệt phần giới thiệu trường và thông tin tuyển sinh 10 năm học 2026–2027. Hình ảnh hero đang dùng ảnh tham khảo từ Tiền Phong.
